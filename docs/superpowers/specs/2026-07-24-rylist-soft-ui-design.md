# RYLIST — إعادة تصميم Soft UI / Neumorphism + وضع فاتح/داكن

> التاريخ: 2026-07-24 · الحالة: معتمد الاتجاه (النموذج أعجب العميل) · النطاق: الموقع العام فقط

## 1. الهدف
تحويل الطبقة البصرية لموقع RYLIST العام من هوية "silent luxury" الحالية (حواف حادة، خطوط رفيعة، تباين عالٍ)
إلى **Soft UI / Neumorphism**: أسطح بلون واحد دافئ، ظلال ناعمة مزدوجة (ضوء + عتمة) تُبرز العناصر،
زوايا دائرية، أزرار "بارزة" تنضغط عند اللمس. مع إضافة **زر تبديل فاتح/داكن** يحفظ اختيار الزائر.

النموذج المعتمد: `scratchpad/rylist-neu.html` (Artifact).

## 2. المبادئ (ما الذي يتغيّر وما الذي يبقى)
- **يبقى**: بنية HTML وأسماء الكلاسات كما هي (عشان JS ما ينكسر)، هوية RYLIST (اللون الدافئ + لمسة الذهبي الشامبيني + الخط العربي Amiri)، ثنائية اللغة و RTL.
- **يتغيّر**: الظلال والحواف والزوايا والخلفيات فقط — أي `styles.css` بشكل أساسي.
- **قرار الأسطح**: في الوضع الفاتح كل الأقسام تصبح سطحًا فاتحًا ناعمًا واحدًا (تختفي الكتل الحبرية الغامقة للهيرو/الفوتر/CTA وتصير ألواحًا ناعمة)، وفي الوضع الداكن كل الموقع سطح داكن ناعم. هذا مطابق للنموذج المعتمد.

## 3. نظام التوكنز (يُضاف إلى styles.css)
```
الفاتح:  --surf #e9e3d5 · --sh-dark #c6bda6 · --sh-light #fdf9f0 · نص #2f2a22 · شامبين #9c8149
الداكن:  --surf #242018 · --sh-dark #141109 · --sh-light #332e23 · نص #ece6d8 · شامبين #bfa572
الظلال:  --raise (بارز)  ·  --inset (غائر)  ·  نسخ -sm أصغر للعناصر الصغيرة
الزوايا: بطاقات ~22px · حبوب/أزرار 999px
```
تُعرّف التوكنز على `:root`، وتُعاد في `@media (prefers-color-scheme: dark)` و `:root[data-theme="dark/light"]`
حتى يفوز اختيار الزائر على تفضيل النظام في الاتجاهين.

## 4. المكوّنات (خريطة إعادة التنسيق)
| المكوّن | الآن | يصبح |
|---|---|---|
| الأزرار `.btn` | مسطّح حبر/شبح | حبّة بارزة بظل مزدوج، تنضغط `:active` = inset؛ `--primary` = تدرّج شامبيني |
| بطاقات الخدمات/المشاريع/الأخبار | حدّ 1px | لوح مرتفع بظل، بدون حدود |
| الصور (بطاقات، هيرو، معرض) | حدّ | داخل إطار غائر (inset well) |
| الحقول/الفلاتر/البحث/النماذج | حدّ | حقول غائرة (inset) |
| الهيدر/التنقّل | حد سفلي | حبّة تنقّل غائرة، الرابط النشط = حبة بارزة |
| الشارات/الحبوب/الأسعار | مسطّح | حبوب ناعمة (بارز/غائر) |
| الهيرو/الفوتر/CTA/البانر | كتل حبر غامقة | ألواح ناعمة بلون السطح (تتبع الثيم) |
| ودجت فاهم + الطافيات (FAB/واتساب) | جزئيًا ناعم | توحيد على نفس نظام الظل |

## 5. زر الوضع الفاتح/الداكن
- **الزر**: يُحقن عبر `main.js` في `.topbar` (مكان واحد → يظهر بكل الصفحات وصفحات التفاصيل المولّدة). أيقونة شمس/قمر، `aria-label` مترجم.
- **الحفظ**: `localStorage['rylist-theme']` = `light|dark`. الافتراضي = تفضيل النظام (`prefers-color-scheme`).
- **منع الوميض (FOUC)**: سطر inline صغير في `<head>` لكل صفحة يقرأ الحفظ ويضبط `data-theme` على `<html>` قبل الرسم. (٧ صفحات + قالبان)
- التبديل يضيف/يزيل `data-theme` على `<html>` ويحدّث `localStorage`.

## 6. إمكانية الوصول (مخاطر Neumorphism)
- النص لا يُنقش أبدًا — يبقى تباينه عاليًا (نص داكن على سطح فاتح والعكس) فوق AA.
- `:focus-visible` حلقة واضحة على كل العناصر التفاعلية.
- احترام `prefers-reduced-motion` (موجود) و `prefers-contrast: more` (نضيف حدًّا خفيفًا احتياطيًا).
- الظلال قيمها معتدلة عشان ما تصير "طرية زيادة" وتضيع الحواف.

## 7. النطاق
- **داخل**: index, projects, services, about, news, contact, fahem + templates/project.html, templates/article.html.
- **خارج**: لوحة التحكم `admin/` (هوية مستقلة). لا نشر/deploy — تعديلات محلية ومعاينة فقط، والعميل يقرر متى ينشر.

## 8. الاختبار (قبل الاعتماد)
معاينة بصرية لكل صفحة، في الوضعين، مع RTL والجوال:
الأزرار تنضغط · الصور داخل حفر · الحقول غائرة · التبديل يحفظ بعد إعادة التحميل · لا وميض · التباين مقروء.

## 9. المخاطر والتخفيف
- **Neumorphism يقلّل التباين** → نبقيه "Soft UI" (النص والحدود الوظيفية واضحة) لا نقاءً مطلقًا بلون واحد.
- **موقع حيّ** → لا push؛ نعاين محليًا ثم العميل يعتمد وينشر بزره المعتاد.
- **تكرار سطر الـ head** في ٩ ملفات → مقبول ومحدود؛ نوثّقه.
